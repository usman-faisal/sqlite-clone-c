# database in c
this is a small project where i am building a simple sqlite clone from scratch. i am following along with the tutorial over at cstack.github.io/db_tutorial to learn more about how databases work under the hood.

to get this running you can compile the project using clang. just run clang index.c -o index in your terminal and you should be good to go. once it is compiled you can start the program by running ./index and you will see the prompt ready for your commands.
